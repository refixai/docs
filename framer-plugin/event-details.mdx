## Event Detail View Components

Clicking an event opens its detailed analytics view, which includes:

*   **Event Name:** The identifier for the tracked event (e.g., "Link - Features").
*   **Total Clicks/Interactions:** The total count of occurrences for this event within the selected time frame.
*   **Time Period Selector:** Filters data by "Last 7 days," "Last 30 days," or "Last 60 days."
*   **Unique Users:** The number of distinct visitors who performed the action during the selected period.
*   **Trend Graph:** A line graph visualizing interactions or unique users for the event over the selected time period.

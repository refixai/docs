## Key Features

*   **No-Code Event Tracking (Autotrack):** Automatically captures clicks, scrolls and views from day 1.
*   **Integrated Dashboard:** Access analytics (page views, visitors, sources, demographics, event details) within the Framer interface.
*   **Privacy-Focused:** GDPR compliant, uses cookie-less tracking, and hosts data in the EU.
*   **Simple Setup:** Install from the Framer Marketplace and publish to start collecting data.
*   **Interaction Insights:** View engagement with specific elements (buttons, links) to optimize user experience.
*   **Near Real-time Data:** View up-to-date statistics within the Framer plugin panel.
*   **Contextual Views:** See events tracked for the currently viewed page in the Framer canvas.
*   **Event Analysis:** Analyze performance trends (clicks, unique users) for specific events over different time periods (7, 30, 60 days).
*   **Visitor Details:** Identify traffic sources and basic demographics (country, browser, device).
*   **Lightweight:** Lightweight script < 5kb, has no impact on site performance.
